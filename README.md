# 🚀 PyreCrawl MCP Stack (Docker)

Готовый к развертыванию Docker-стек для **[PyreCrawl](https://github.com/SanggonBoy/PyreCrawl)** — мощного, полностью бесплатного и self-hosted инструмента для глубокого веб-поиска, краулинга и извлечения данных. 

PyreCrawl является отличной альтернативой Firecrawl, не требует API-ключей и умеет обходить сложные защиты (включая Cloudflare), используя невидимый браузер Chromium.

Этот репозиторий содержит оптимизированный `Dockerfile` и `docker-compose.yml`, которые не только запускают PyreCrawl, но и автоматически оборачивают его в **[MCPO](https://github.com/open-webui/mcpo)** (MCP-to-OpenAPI proxy). Это позволяет подключать сервер к веб-интерфейсам (например, **Open WebUI**) по HTTP, а не только через локальный stdio.

## ✨ Возможности

*   **🕵️‍♂️ Глубокий поиск:** Переход по ссылкам, обход блокировок и парсинг динамического контента.
*   **📄 Извлечение данных:** Преобразование страниц в чистый Markdown, извлечение структурированных данных (таблиц, списков) по схеме.
*   **🔓 Без API-ключей:** Работает «из коробки» без необходимости регистрироваться в платных сервисах.
*   **🌐 HTTP-доступ (MCPO):** Встроенный прокси-сервер транслирует MCP-инструменты в стандартный REST API (порт `8000`).
*   **🐳 Docker-ready:** Полная изоляция зависимостей и браузера.

## 🚀 Быстрый старт

Убедитесь, что у вас установлен Docker и Docker Compose.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/fastforsage/pyrecrawl-stack.git
   cd pyrecrawl-stack
   ```

2. Запустите сборку и старт контейнера:
   ```bash
   docker compose up -d --build
   ```
   > ⏳ *Примечание: Первая сборка может занять от 5 до 15 минут, так как контейнер скачивает системные библиотеки, Python-пакеты и полноценный браузер Chromium.*

3. Проверьте статус:
   ```bash
   docker compose ps
   ```

## 🔌 Интеграция с Open WebUI (и другими клиентами)

Благодаря встроенному MCPO, сервер доступен по адресу `http://<IP-вашего-сервера>:8000`.

**Для добавления в Open WebUI:**
1. Перейдите в **Settings** -> **Admin Settings** -> **Integrations** (или **Tools**).
2. Нажмите **+ Add Server** (добавить MCP-сервер).
3. Укажите URL: `http://localhost:8000` (если Open WebUI и PyreCrawl в одной сети Docker).
4. Сохраните. Инструменты (`search`, `scrape`, `crawl`, `deep_research`) станут доступны вашим моделям.

## 📂 Структура проекта

*   `Dockerfile.pyrecrawl` — Инструкция сборки: установка `uv`, `pyrecrawl`, `mcpo` и браузера Chromium.
*   `docker-compose.yml` — Конфигурация контейнера, проброс порта `8000` и volumes для кэша.

## 🛡️ Безопасность и конфиденциальность

Все запросы выполняются с вашего сервера. Стек полностью автономен, телеметрия PyreCrawl отключена по умолчанию (`PYRECRAWL_NO_TELEMETRY=1`). Кэш результатов сохраняется в Docker volume для ускорения повторных запросов.
